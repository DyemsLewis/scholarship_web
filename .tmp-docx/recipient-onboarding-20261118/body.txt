019 [] 11. Create a handoff only when its real prerequisite exists; do not make an actual payment.
020 [] 12. Combined views last: orivanta.manager and orivanta show organization-wide provider access. lumenops.manager shows read-only portal oversight; lumenops.root handles admin-team governance. Do not use these views to imply that every specialist decision is an oversight action.
021 [] Optional branches include eligibility reconsideration, correction requests, delivery disputes, withdrawal, agreement concerns and appeals. Read their prerequisites before starting. Required notice and reminder periods cannot be compressed into a few minutes by backdating records. Demonstrating the available form is not the same as completing that branch.

Required confirmed mismatches block a new application unless the provider has explicitly enabled and approved reconsideration for every blocking rule. Preferences do not need an exception. Use the separate Eligibility reconsideration controls only for rules the provider is genuinely willing to reconsider.

230 [Heading2] Request eligibility review before applying
231 [] Signed in account: Applicant with a verified profile then orivanta.reviewer
232 [] This optional branch requires a published open program with provider-enabled reconsideration. It is not a pending request in the prepared dataset. Never falsify the applicant profile to create a match or a mismatch.
233 [] 1. In scholarship details open Eligibility. If every confirmed blocking rule permits reconsideration choose Request eligibility review.
234 [] 2. Explain the circumstances in 20 to 2000 characters. Optionally attach one JPG PNG WebP or PDF up to 5 MB. Unlike receipt confirmation this eligibility attachment is optional.
235 [] 3. Acknowledge accurate information review the confirmation and send the request. It does not submit an application reserve a slot or select the applicant.
236 [] 4. Read the provider response in the same Eligibility section and use Refresh status. Approval permits applying only for the reviewed profile rules and intake; relevant changes require a fresh review.
237 [] 5. Continue to the normal application only after approval and all other safeguards are met. The original mismatch and provider exception remain visible in the saved comparison.
